# WXATA - WhatsApp Bot Plan

## Overview
WXATA is a high-performance WhatsApp bot built with **Baileys** and powered by **Bun**. It is designed to run on a VPS or backend system, providing interactive features like games and code-based chat utilities.

## Tech Stack
- **Runtime**: [Bun](https://bun.sh/) (Fast JS/TS runtime)
- **Library**: `@whiskeysockets/baileys` (WhatsApp Web API)
- **Frontend**: Vite + React + Tailwind CSS + Framer Motion
- **Styling**: Neon Green on Pure Black theme

## Core Features
1. **Interactive Games**: Trivia, RPG elements, and group-based interactive games.
2. **Code-Only Features**: 
   - Sandboxed code execution.
   - Advanced media manipulation.
   - Custom chat automations.
3. **VPS Optimized**: Designed for 24/7 uptime on remote servers.
