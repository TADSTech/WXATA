Features

⚡

Bun Runtime

Blazing fast startup and execution with the Bun JavaScript runtime.

🔗

Dual Accounts

Run primary and secondary WhatsApp accounts simultaneously.

🛡️

Anti-Delete

Recover deleted messages with local SQLite caching.

🖥️

Live Dashboard

Real-time WebSocket dashboard for logs, QR codes, and control.

🧩

Command System

Built-in commands + custom JS script execution in botinfo.json.

📡

Developer API

REST API for sending WhatsApp messages programmatically.

🎬

TV Mode

Restrict bot to root user only for personal automation.

👥

Group Tools

Warn system, tag-all, anti-broadcast, and more.

Built-in Commands

+menu Show bot menu
+ping Check bot status
+help List commands
+tagall Mention everyone
+warn Warn a member
+antidel Show deleted msgs
+sticker Image → sticker
+ss Screenshot URL
+vars Manage variables
+perm Permissions

Quick Start

# Clone
git clone https://github.com/TADSTech/wxata.git
cd wxata

# Setup (Windows)
.\setup.ps1

# Setup (Linux/Mac)
chmod +x setup.sh && ./setup.sh

# Run
bun run all
1

Clone & Setup

Run the setup script to install dependencies and create config files.

2

Configure

Edit .env and botinfo.json to your needs.

3

Connect

Open the dashboard, scan the QR code, and you're live.
