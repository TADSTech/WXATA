WXATA

FOSS WhatsApp Automation & Tactical Assistant

Built on Baileys + Bun. Connect your WhatsApp, write custom scripts, and automate anything.

Get Started View on GitHub

Features

⚡

Bun + Baileys

High-performance runtime with the best WhatsApp Web library. No Chrome needed.

🧩

Custom Scripts

Add your own commands via botinfo.json. No code changes required — just config.

🛡️

Anti-Delete

SQLite-backed message cache. Retrieve deleted messages on demand.

📊

Live Dashboard

Real-time logs, QR pairing, connection status — all in a React dashboard.

🔑

Permissions

Granular command permissions. Control who can use what.

🚀

One-Command Deploy

Docker or PM2. Deploy to any VPS in seconds.

🏪

Plugin Marketplace

Install community-built plugins with one click. Browse, download, and import.

🔌

JSON Plugin Files

Standard script format. Download from marketplace, import to dashboard, done.

Built-in Commands

+menu Show menu
+ping Health check
+help List commands
+tagall Mention all
+warn Warn member
+antidel Deleted msgs
+sticker Image → sticker
+ss <url> Screenshot
+vars Bot variables
+perm Permissions

Quick Start

1

Clone & Install

Clone the repo and run the setup script.

2

Configure

Edit .env and botinfo.json with your settings.

3

Run

Start the bot and scan the QR code from the dashboard.

git clone https://github.com/TADSTech/wxata.git
cd wxata
.\setup.ps1          # Windows
bun run all          # Start frontend + backend

Architecture

Frontend (Vite + React)
  │  WebSocket
  ▼
Backend (Bun + Baileys)
  ├── WhatsApp Protocol
  ├── SQLite (message cache)
  ├── botinfo.json (config)
  └── Firebase (optional)
