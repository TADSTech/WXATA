WXATA Documentation

Welcome to the official documentation for WXATA — the FOSS WhatsApp Automation & Tactical Assistant.

WXATA is built on Baileys and Bun, designed for high-performance automation. Connect your WhatsApp account, write custom scripts, and automate anything.

Getting Started

Prerequisites

  • Bun runtime
  • Node.js 18+ (for compatibility)
  • Git

Installation

# Clone the repository
git clone https://github.com/TADSTech/wxata.git
cd wxata

# Run the setup script
# Windows:
.\setup.ps1

# Linux/Mac:
chmod +x setup.sh
./setup.sh

# Or manually:
cp .env.example .env
cp botinfo.example.json botinfo.json
bun run install:all

Configuration

.env

VariableDefaultDescription

FIREBASE_PROJECT_ID—Firebase project (optional)

botinfo.json

The main bot configuration file. Controls commands, prefix, permissions, and behavior.

{
  "prefix": "+",
  "scripts": { ... },
  "root": { "target": "self" },
  "welcome": { "enabled": true, "text": "Welcome!" },
  "permissions": { "allowAll": true }
}

Commands

WXATA ships with built-in commands. The prefix is configurable (default: +).

CommandDescription
+menuShow the bot menu
+pingCheck if bot is alive
+helpList available commands
+tagallMention all group members
+warnWarn a member (3 = kick)
+antidelShow deleted messages
+stickerConvert image to sticker
+ss <url>Screenshot a website
+varsView/set bot variables
+permManage permissions

Custom Scripts

Add your own commands by editing botinfo.json:

{
  "scripts": {
    "hello": {
      "name": "Hello",
      "desc": "Say hello",
      "trigger": "hello",
      "aliases": ["hi"],
      "type": "fun",
      "response": "Hello there!",
      "target": "chat",
      "code": ""
    }
  }
}

Script Fields

FieldTypeDescription
namestringDisplay name
descstringDescription
triggerstringPrimary trigger word
aliasesstring[]Alternative triggers
typestringCategory: core, tools, admin, group, fun
responsestringStatic reply text
targetstringWhere to send: chat, self, or phone number
codestringOptional JS code for dynamic execution

Dashboard

The dashboard runs alongside the backend on port 5000. Open http://localhost:5173 (dev) or your server IP (production).

Features

  • Real-time log streaming via WebSocket
  • QR code and phone pairing for WhatsApp connection
  • Bot info and script management
  • Connection status monitoring
  • PM2 process status

Deployment

Docker

docker compose up -d

PM2 (Production)

bun run pm2:start    # Start
bun run pm2:restart  # Restart
bun run pm2:logs     # View logs
bun run pm2:status   # Status

Oracle Cloud / VPS

Use deploy-oracle.sh for automated Oracle Cloud deployment. See the script for details.

Developer API

WXATA includes a REST API for sending WhatsApp messages programmatically.

Send a Message

POST /api/send
Content-Type: application/json

{
  "to": "2348012345678",
  "message": "Hello from WXATA!"
}

Note: The API requires the bot to be connected and the endpoint is protected by ADMIN_SECRET if set.
