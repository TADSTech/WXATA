# Sticker Assets for TV Miniapp

Place your branding stickers in this folder.
The image processing script uses the following names exactly:

1. `sticker1.png` - This will be placed in the **Top-Left** (Northwest) corner.
2. `sticker2.png` - This will be placed in the **Bottom-Right** (Southeast) corner.

If these files exist, they will be automatically scaled to 15% of the downloaded image width and overlaid onto the memes or Twitter images before posting to your status.

If they are missing, the images will just be posted without branding.
